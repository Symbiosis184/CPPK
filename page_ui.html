🛠 Памятка инженера: перепрошивка и настройка билетомата BPA/APB

1. Прошивка ядра и приложения

  1. После прошивки ядра — нажать 0.
  2. Download app → RS232 → прошить UPOS.

2. Вход в сервисное меню (Сбер)

  • Тап на логотип Сбер (или клавиша 5 на старом терминале).
  • Код доступа: 028510

3. Настройка связи (статический IP)

  1. Настройки → Настройка связи → Каналы → Ethernet.
  2. Нажать 1, затем: Нет → Да (статика).
  3. Ввести IP-адрес, маску, шлюз (значения — в карточке объекта, см. поиск выше).
  4. Выйти, сохранить.

4. Обновление ПО и активация

  1. Основное меню → Обновление → Обновить ПО.
  2. После обновления → Лицензирование:
    • Активация с сервера: KLA, RKL;
    • Загрузка KLK-ключа.
  3. Главное меню → Загрузка ключей → Сверка итогов.

5. Функции сервисного меню (код + номер функции)

КодФункция
0Тест связи
13Удаление транзакций
19Снять Reversal
40Сверка итогов
44Проверка SN / KLK-ключей
45Удаление сертификатов
50Загрузка параметров
Примечание: 40 — сверка итогов, 44 — проверка ключей, 45 — удалить сертификат.

6. Сетевые настройки конкретного объекта

IP/VLAN/шлюзы по каждому билетомату — в поиске рядом (по городу или № билетомата). Удобно включить кнопку «⬜ Рядом» в шапке: памятка останется слева, а результаты поиска — справа.

Внутренний инструмент. Загруженная база хранится на сервере в upload_store.json.
